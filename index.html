How to read this view

Each dot is one included sensory event. Spokes connect an event to its visual group; they are not causal, social or temporal connections. Combinations use the broad sensory modes shown here. Original codes remain available in the event details. Events without coordinates are included here. The map uses the first supplied location for each event to avoid duplicating dots; all source locations remain in Source information.

About this pilot

VERSE explores how sensory experience and sensory uncertainty are narrated in vernacular traditions.

This demonstrator contains 600 sampled narratives: 150 each from the Latvian, Norwegian, Finnish and Swedish datasets. English working translations are available for 24 selected narratives. Translation notes retain unresolved readings.

Reading the annotations

This version contains 673 provisionally identified sensory events, 344 unresolved event candidates and 1,291 response annotations. Only sensory events contribute to the map and research graphs. The optional response and candidate layers appear in the original-text reader. A single event may have several evidence passages and still counts once.

Provisional pilot annotations. Model-reviewed, not human-validated. Detailed comparison with previous coding remains incomplete. The earlier broad selection contained 1,228 events; the revised selection uses different inclusion and event-boundary rules. The reduction does not establish previous errors or improved accuracy.

Colour identifies sensory modes. Bodily experience groups tactile, temperature, pain, bodily and vestibular codes. Event details retain the original labels, perceptual status, contextual fields and exact supporting evidence. Narrated uncertainty is separate from analytical uncertainty and candidates. Absence of a code does not establish absence of uncertainty.

Responses may be emotional, bodily, behavioural or verbal. Their links can be supported, ambiguous or unassigned; targets may also be unresolved candidate events. Unassigned responses are not confirmed consequences of sensory events. Responses never add sensory-event dots or counts.

All 24 English working translations are retained below the originals. Their sensory highlights are linked to the same 59 events and 83 evidence passages as the originals, using the same event IDs and sensory categories. Translation and passage alignment have not been human-validated. Response and unresolved-candidate layers remain available in the original only. Working glosses are separate aids, not verified translations or independent annotations.

Event constellations & configurations

The default Sensory mix view shows one dot per sensory event, arranged in a golden-angle spiral around its first supplied source place. Fine lines show visual displacement, not travel, causality or exact event locations. The configuration explorer includes events without coordinates. It groups events by broad sensory combination, uncertainty coding or collection. The combination controls offer at least one, contains all and exact matching of selected modes. Original annotation codes remain available when an event is selected. Concentration shows event counts, whereas Collections and optional summary rings count narratives.

Comparison and flow

Comparison bars show shares of sensory-category links, with each multimodal event contributing once to each of its modes. Counts are conditional on active filters. Flow positions each event at the start of its first evidence passage and links events in source-text order, not elapsed time or causation. Multiple passages belonging to one event do not create extra points. Concentration uses soft fields around supplied source coordinates with logarithmic weighting. Intensity controls visual strength; Radius controls smoothing from 12 to 80 screen pixels, starting at 24 pixels. Hover targets follow the supplied coordinates; smoothing does not indicate geographic extent or positional certainty. Hue shows the strongest local sensory category, with brightness indicating its concentration. Select individual categories to inspect overlapping layers. This is not a regional prevalence or equal-area density estimate.

Map locations

Map markers represent supplied source places, not necessarily narrated event locations. Norwegian coordinates may refer to broad areas. Finnish records use approximate reference points for Vesilahti, Lempäälä and Sääksmäki, added from GeoNames/OpenStreetMap via Mapcarta; these are not precise collection sites. Multiple source places are retained where supplied. Records without coordinates remain accessible. Nearby points are grouped at the current zoom; counts refer to distinct narratives in each marker.

Sources & scope

The interface retains available source references from the supplied pilot datasets. Swedish records come from Sagenkartan. Texts and source metadata retain their respective source rights. This purposive pilot view is for exploration, not population-level comparison or frequency claims.

No accounts, tracking or automatic translation. All reading and filtering run in your browser. The optional detailed basemap loads tiles from OpenStreetMap; the built-in overview map works offline.
